## 1. Как устроен проект

```
/
├── index.html                 главная страница — весь сайт: разметка, стили, скрипты
├── privacy/index.html         Политика обработки персональных данных
├── consent/index.html         Согласие на обработку персональных данных
├── assets/
│   ├── legal.css              стили страниц /privacy и /consent, подвала с реквизитами и cookie-баннера
│   └── cookie.js              cookie-баннер «Принимаю / Настроить»
├── img/                       все изображения (фото объектов, логотип, письма, og-image, иконки)
├── favicon.ico                иконка сайта (16–256 px)
├── apple-touch-icon.png       иконка для iOS, 180×180 на белом
├── robots.txt                 правила для роботов, ссылка на sitemap
├── sitemap.xml                карта сайта (3 адреса)
├── vercel.json                настройки Vercel (см. раздел 4)
└── yandex_56632094e8e1b94d.html   подтверждение прав в Яндекс Вебмастере — НЕ УДАЛЯТЬ
```

Сборки нет: что лежит в репозитории, то и отдаётся посетителю.
Источник правды — `index.html` в ветке `main`.

### Локальный запуск

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Яндекс Форма во встроенном окне и Метрика работают и локально (нужен интернет).

### Публикация

Каждый `git push` в `main` → Vercel сам собирает и выкладывает новую версию за 20–40 секунд.
Ветки, отличные от `main`, получают preview-адрес вида `centurion-git-<ветка>-damirenero.vercel.app` — удобно показать правки до публикации.

### Где менять частые вещи

- **Телефон и e-mail** — константа `CONTACTS` (`email` — основной info@sk-centurion.ru, `email2` — centurion.build.co@bk.ru) в начале основного `<script>` внизу `index.html`. Также они продублированы в подвале, в JSON-LD (`telephone`, `email`) и на страницах `/privacy`, `/consent` — менять везде (поиск по `927` и `bk.ru`).
- **Цвета** — CSS-переменные в `:root` в начале `<style>`.
- **Объекты** — карточки внутри `<div class="projects">`. Фото класть в `img/`, ширина 1600 px, JPEG ~80%.
- **Вопросы FAQ** — менять и в блоке `#faq`, и в JSON-LD `FAQPage` в `<head>`, тексты должны совпадать.
- **Тексты политики и согласия** — `privacy/index.html`, `consent/index.html`. Тексты юридические, сделаны из документов клиента дословно — правки только по согласованию с клиентом.

### Анимация первого экрана

Рисуется скриптом в SVG `#scene` (второй `<script>` блок, `(function(){ const NS=... })`):
1. линии чертежа прорисовываются (`stroke-dashoffset`, задержки `--d`);
2. сканирующая линия идёт снизу вверх и «зажигает» здание;
3. сверху вниз проходит линия-шторка `#wipe` и открывает фото `img/hero-photo.jpg` (`#stage-photo`).

Не зацикливается; кнопка «Повторить» перезапускает. При `prefers-reduced-motion` анимация не проигрывается.

Почта на домене — Рег.ру «Почта-1» (услуга u3721402, бесплатно по Рег.решению до 11.11.2027, далее платно): ящик `info@sk-centurion.ru`. В зоне `sk-centurion.ru` её записи: MX `mxs1.reg.ru` / `mxs2.reg.ru`, TXT SPF, DMARC, DKIM — не удалять.

DNS у обоих доменов — на бесплатных серверах Рег.ру (`ns1.reg.ru`, `ns2.reg.ru`). Записи одинаковые:

```
A      @     216.198.79.1
CNAME  www   576526847f66bd64.vercel-dns-017.com.
```

Значения выдаёт Vercel («View DNS configuration» у домена). Если Vercel их поменяет — он покажет новые, их надо перенести в Рег.ру.
SSL-сертификаты Vercel выпускает и продлевает сам.

Домены оплачены до **10.11.2027**, автопродление в Рег.ру включено, но для его срабатывания нужна привязанная карта или деньги на балансе.

- ID: `6af0c5956d2d736555e02628`, адрес: https://forms.yandex.ru/u/6af0c5956d2d736555e02628/

- Включена капча.
- Ответы: хранятся в самой форме (вкладка «Ответы») + уведомление на почту автора формы, `info@sk-centurion.ru` и `centurion.build.co@bk.ru` со всеми полями.

### Яндекс Метрика

- Счётчик **113843617**, код вставлен напрямую в `<head>` всех трёх страниц (главная, privacy, consent), с Вебвизором.
- По решению заказчика счётчик запускается сразу, не дожидаясь согласия в cookie-баннере. Баннер (`assets/cookie.js`) при этом остаётся: показывает уведомление и сохраняет выбор в `localStorage` (`centurion-cookie-consent`). Если нужно запускать Метрику только после согласия — убрать код счётчика из `<head>` и вписать номер в `METRIKA_ID` в `assets/cookie.js`.

## 7. Известные моменты и что стоит сделать

- **Vercel Hobby** предназначен для некоммерческих проектов. Для сайта компании по правилам Vercel нужен тариф Pro — либо перенос на российский хостинг (статика переносится как есть, затем поменять DNS-записи в Рег.ру).
- **Google Fonts** грузятся с серверов Google (передача IP посетителя за рубеж). Если потребуется строгое соответствие 152-ФЗ — скачать шрифты в `assets/fonts/` и подключить локально через `@font-face`.
- **Метрика до согласия** — см. раздел 5, решение заказчика.
- В `<head>` главной есть служебный мета-тег `claude:viewport-fit-sides` — ни на что не влияет, можно удалить.
- Иконка в выдаче Яндекса появляется с задержкой (робот иконок обходит сайт раз в несколько дней).
- Рекомендуется: карточка организации в Яндекс Бизнесе со ссылкой на сайт; Google Search Console; отдельные страницы под ключевые услуги для SEO.
